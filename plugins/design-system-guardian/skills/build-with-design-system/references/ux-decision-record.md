# UX decision record

Create this record before editing product UI and bind it to the Guardian run.

Required fields:

- `runId`, `profileId`, `policyDigest`, `snapshotId`, and source-cut digest
- generated adapter config digest bound to that same pinned snapshot
- user goal and primary task
- information hierarchy and component intent
- normal, empty, loading, error, disabled, success, and permission states as applicable
- keyboard, focus, screen-reader, contrast, reduced-motion, and touch-target considerations
- one exact planned identity plus resolution request for every component, icon, color, typography, spacing, radius, effect, and motion choice
- normal product copy with the approved text component and presentation identities
- known design-system gaps; never an unauthorized workaround

Update the record if product intent changes. Do not switch the pinned snapshot or silently replace a blocked identity.
